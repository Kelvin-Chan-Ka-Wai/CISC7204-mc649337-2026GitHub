## Practice 09 - Data science portfolio (October 2026)

The Practice 09 activity asked for a project repository, a portfolio page and a GitHub Pages
deployment. That work lives in its own public repositories and is archived here in
[`practice-09-ds-portfolio/`](practice-09-ds-portfolio/):

The project visualises three public datasets with Bokeh: World Bank population density
(Germany vs Switzerland, 1961-2015), the UCI 1985 automobile market (mean price per
manufacturer) and the Rio 2016 Olympic athletes (medals vs delegation size).
