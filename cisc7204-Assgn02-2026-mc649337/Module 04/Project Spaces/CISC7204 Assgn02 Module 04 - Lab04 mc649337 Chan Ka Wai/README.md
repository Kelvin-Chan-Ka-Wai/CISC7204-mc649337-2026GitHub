# Module 04 Lab04 - Flight Delay Time Statistics Dashboard

CISC7204 Assignment 02 - Module 04 Dash project space.

## Files
- `flight_delay.py` - the Dash application, written task by task (TASK 1 ... TASK n comments)
- `data/airline_data.csv` - dataset used by the application
- `requirements.txt` - Python packages needed to run it
- `README.md` - this file

## Run

```bash
python -m pip install -r requirements.txt
python flight_delay.py  ->  http://127.0.0.1:8053
```

Then open the URL printed in the terminal. Stop the running application with **CTRL + C** in the
terminal (this is the answer to the "stop the running app" practice task).
