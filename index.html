How it is built

Every lab was executed from top to bottom in Jupyter Notebook with the Python (Assignment 02) kernel; the Dash applications were written task by task in the Theia IDE and captured while running. The repository keeps the exact submission folder:

  Datasets/                  the datasets used by the labs
  Module 01 … Module 05/     Jupyter Notebooks · Screen Shots · Project Spaces
  Module01.zip … Module 05.zip   the packaged modules
